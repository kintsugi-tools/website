The toolkit

Three tools. One principle.

Each does one job, runs entirely on your machine, and installs with a single command.

01
01 — Safety for AI agents

Your agent has shell access. Give it a conscience.

Kintsugi sits between your AI coding agent and the shell. Destructive commands are caught before they run, held for your approval, and made reversible — locally, every time.

  • Deterministic rules — never an LLM decision
  • Copy-on-write snapshots and one-command undo
  • Append-only, hash-chained audit log

02 — Document search

Ask your documents. Get the exact receipt.

Paper is local-first AI document search that answers with exact citations — the file, the page, the line. One binary gives you a CLI and an MCP server.

  • PDF, DOCX and 15+ formats; OCR for scans
  • 100+ languages, zero-touch first run
  • No cloud, no API keys, no telemetry

03
03 — Test acceleration

Compile less. Test less. Trust the results.

Oryn is a safe, Rust-native accelerator for Cargo test suites. It runs only the tests your change can affect, skips the ones it can prove unchanged, and never trades correctness for speed.

  • Runs only tests your change can affect
  • Sound cache — never a wrong result
  • Real statistics for flaky tests · No AI, no nightly

Your data stays yours

Documents, shell history, source code, test results — none of it leaves your machine. There is no account, no upload, and no API key to manage.

Works offline, forever

No service to go down, no pricing change, no deprecation notice. Each tool installs its own models and dependencies on first run and keeps working without a network.

Deterministic, not probabilistic

Kintsugi's safety decisions come from deterministic rules and a real shell parser — an LLM may explain a command, but it never decides whether it is safe.

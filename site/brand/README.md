# Kintsugi brand kit

The mark is a rounded-square tile cracked by gold seams that draw a K. The wordmark is outlined
Inter Display Bold, "kintsugi" (dotless i) with gold diamond dots. All SVGs are outlined; no fonts needed.

## Files
| File | What it is |
|---|---|
| `kintsugi-mark.svg` | Mark, ink tile. Use on light backgrounds. |
| `kintsugi-mark-on-dark.svg` | Mark, cream tile. Use on dark backgrounds. |
| `kintsugi-mark-mono-black.svg` / `-mono-white.svg` | Single-colour mark for print, engraving, legal documents. |
| `kintsugi-lockup*.svg` | Mark + wordmark side by side (same four variants: default, `-on-dark`, `-mono-black`, `-mono-white`). |
| `kintsugi-stacked.svg` / `-on-dark.svg` | Mark above wordmark, for square or centred spaces. |
| `kintsugi-wordmark.svg` / `-on-dark.svg` | Wordmark only. |
| `*-512.png`, `*-1024.png` | Transparent PNG exports of each mark variant. |
| `kintsugi-lockup*-2000.png`, `kintsugi-stacked*-2000.png` | Transparent PNG exports, 2000 px wide. |
| `og-source.html` | Source of `../og.png` (1200x630 share image). Regenerate by screenshotting it at exactly 1200x630. |

## Rules
- **Clear space:** about 1/4 of the tile (the height of the gold seam's jog) on all sides.
- **Minimum size:** 16 px for the mark, 80 px wide for the lockup.
- **Colours:** ink `#0B0E13`, cream `#F3F1EA`, gold `#D4A62A`.
- **Typeface:** Inter Display Bold, converted to outlines (SIL Open Font License).

## Don't
- Don't recolour the seams.
- Don't rotate.
- Don't add effects or glow.
- Don't stretch or change proportions.
- Don't place the ink tile on dark backgrounds (use the on-dark variant).
